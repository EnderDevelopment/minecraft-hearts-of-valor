# Hearts of Valor

Hearts of Valor is a Minecraft plugin that introduces a unique advancement system inspired by the Hearts of Iron mod. This plugin adds 11 new advancements, each with challenging objectives that players must complete to unlock. The advancements are designed to be difficult, rewarding players with unique titles and messages upon completion. The plugin is compatible with Minecraft version 1.21 and requires a Spigot or Paper server to function.

## Install

1. Download the plugin JAR file from the GitHub repository.
2. Place the JAR file in the `plugins` folder of your Spigot or Paper server.
3. Start or restart your server to load the plugin.

## Use

1. Launch your Minecraft client and connect to the server running the Hearts of Valor plugin.
2. Begin completing the objectives for each advancement. The advancements and their objectives are as follows:

### Sky Conqueror (Cloud Heart, HARD)
- Travel 10,000 blocks
- Survive 10 dangerous falls using fall-saving methods

### Trial Champion (Mace Heart, HARD)
- Clear 5 Trial Chamber trials
- Obtain a Heavy Core

### Packmaster (Dog Heart, VERY HARD)
- Tame 9 wolf variants: Pale, Woods, Ashen, Black, Chestnut, Rusty, Snowy, Spotted, Striped
- Defeat 100 hostile mobs

### Soul Hunter (Lifesteal Heart, VERY HARD)
- Win 15 PvP fights
- Defeat the Wither

### Unbreakable (Defense Heart, EXTREME)
- Obtain full Netherite armor
- Defeat Wither, Elder Guardian
- Obtain Nether Star, Trident
- Complete without dying

### Death's Touch (Wither Heart, VERY HARD)
- Defeat 50 Wither Skeletons
- Obtain Wither Skeleton Skull

### Web Walker (Web Heart, EXTREME)
- Obtain 128 Cobwebs
- Defeat 10 Cave Spiders, Warden
- Explore Ancient City, escape alive
- Obtain Spider Eye, Fermented Spider Eye
- Complete without dying

### Void Conqueror (Void Heart, VERY HARD)
- Discover End City
- Defeat Ender Dragon
- Obtain enchanted Diamond armor, Elytra
- Collect 16 End Crystals

### Cosmic Ascension (Cosmic Heart, LEGENDARY)
- Defeat Ender Dragon
- Obtain Dragon Egg

### Death's Awakening (Undead Heart, VERY HARD)
- Defeat 50 hostile mobs
- Defeat 10 enemies during nighttime
- Complete Bone Curse's five-hit combo

### Mochi's Blessing (Mochi's Heart, SECRET CHALLENGE)
- Tame a wolf
- Breed two animals
- Collect pink flower, obtain cake
- Survive a night without dying

### The Ninefold Legend (LEGENDARY)
- Unlock all nine original Heart advancements
- Complete all nine Heart challenges
- Rewards: Exclusive title, special completion message

3. As you complete each advancement, you will receive a unique message in the chat indicating that you have unlocked the advancement.
